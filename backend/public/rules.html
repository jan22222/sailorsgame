Sailors & Islands — Game Rules

Goal

  • The first player reaching 30 points wins the game.

Setup Phase

  • Players build in this order: 1 → 2 → ... → N → N → ... → 1.
  • Each turn allows building one structure only.
  • No resources are produced during setup.
  • The game begins automatically after setup.
  • Warning: If you are the Nth player: Build, skip, build again, then skip. Make sure you build twice.
  • Warning: If you build a ship first, connection rule already exists. If you build a boat, that is not the case.

Main Game

  • At the start of each turn a dice roll distributes resources.
  • If a 7 is rolled, the dice rolls again. Only if a second 7 appears, the 7 counts.
  • Players may build houses, ships, and trade resources.

Buildings

  • House: increases points and produces resources. Costs 2-1-2 mud-sheep-wood
  • Ship: costs resources but gives more points. Costs 5-5 ore-wheat

Trading

  • Players may trade 4:1 with the bank.

Trading

  • Players may trade 4:1 with the bank.

Winning

  • You reach 30 points, you win.
