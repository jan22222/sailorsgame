Sailors & Islands — Rules

Always accessible via the “?” icon in-game.
← Back

Goal

  • The game ends after 15 rounds.
  • The winner is the player with the most victory points.

Key Terms

  • Tile: hex field with a resource type and dice number.
  • Place (Vertex): build spot on the map (clickable points).
  • Boat: normal building.
  • Ship / Big Boat: advanced building that collects double.
  • Distance: measured along vertex connections (edges). Distance 2 = exactly one vertex between.

Phases

1) Setup Phase

  • Each player places exactly 2 Boats.
  • Boats can be placed anywhere on empty places.
  • No distance rule applies during setup.
  • Placing does not instantly grant resources.

2) Build Phase

  • Build only on empty places.
  • You may build only if the target place is at exact distance 2 from an existing own Boat.
  • Ships do not count as anchors for the distance rule.
  • You cannot build on your own building or on enemy buildings.

Costs

  • Boat: (current boat cost).
  • Ship / Big Boat: costs 5 metals + 3 grains, produces double in production.

Turn Flow & Production

  • Timer runs for the active player.
  • When time ends: dice roll → production → next player.
  • Production happens only on dice rolls (not on build).
  • Boat produces 1×; Ship produces 2×.

Game End

  • After 15 rounds: game ends and points decide the winner.
